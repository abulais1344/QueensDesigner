# Queens Collection — AI Build Spec

Build a premium Indian ethnic fashion ecommerce web app for Queens Collection.

## Goal
Create a fresh, high-end shopping website for an Indian clothing brand. The product must feel premium, modern, mobile-first, structured, and highly shoppable. It should feel inspired by Myntra and Ajio, but with a distinct Queens Collection identity. The site must look like a serious fashion ecommerce brand, not a boutique landing page.

## Target audience
- Indian women aged 22–40
- Urban and Tier 2 shoppers
- Interested in festive wear, occasion wear, bridal, suits, lehengas, party wear
- Mobile-first browsing behavior

## Brand direction
- Brand: Queens Collection
- Personality: premium, feminine, modern, elegant, aspirational, refined
- Indian fashion with a contemporary premium aesthetic
- Not overly luxury or overdone
- Not dusty beige or editorial-magazine style
- Should feel clean, polished, trustworthy, and conversion-focused

## Design language
- Modern premium ecommerce visual system
- Primary palette: warm off-white, blush pink, dusty rose, deep maroon, charcoal, muted gold
- Use subtle luxury accents, not clutter
- Modern sans-serif typography for most content
- Optional serif only for brand name or heading accents
- Strong contrast, proper spacing, clear hierarchy
- Rounded buttons, clean cards, organized layout
- High readability on mobile
- Large tap targets
- Product-first design, not text-heavy design

## Must avoid
- dusty beige boutique styling
- generic luxury landing page clichés
- too much serif on everything
- tiny buttons
- crowded layouts
- weak hierarchy
- low contrast typography
- decorative blocks that reduce conversion
- old-school fashion brand template feel

## Tech stack
- React + TypeScript
- Vite
- Tailwind CSS
- React Router
- Lucide React icons

## Core pages

### 1. Homepage
- Top nav with logo, category links, search, wishlist, bag
- Hero section with strong headline and CTA
- Category chips
- Product-first homepage with best sellers and new arrivals
- Mobile sticky bottom nav
- Premium clean footer

### 2. Collections page
- Left filter panel on desktop
- Search field and sort dropdown
- Grid of product cards
- Fashion catalog layout, dense and clean
- Similar energy to Myntra/Ajio but with original styling

### 3. Product details page
- Large image gallery
- Product title, category, price
- Size, color, and CTA
- Product description and fabric details
- Related products

### 4. Wishlist / cart-like interactions
- Add/remove from wishlist
- Basic cart UI states
- No backend required

### 5. Mobile experience
- Sticky bottom nav
- Compact cards
- Large touch targets
- Optimized spacing for mobile shopping

## Product data
- Use realistic Indian fashion product names
- Categories: Bridal, Lehengas, Suits, Festive Wear, Sharara Sets, Party Wear
- Add mock pricing and rating data
- Product cards show image, name, category, price, rating, CTA

## Quality bar
- Make the app feel like a polished ecommerce brand, not a prototype mockup
- Keep the overall look premium, modern, and highly usable
- Think like a serious Indian fashion retailer
- Prioritize discovery, clarity, conversion, and trust
- Build reusable components and clean structure

## Responsive behavior
- Mobile-first layout
- Optimize for thumb-friendly interactions
- Dense product cards on mobile with proper spacing
- Sticky bottom nav on mobile

## Final expectation
Produce a completely redesigned Indian fashion ecommerce web app with a different visual identity, better layout system, stronger typography, cleaner palette, premium look, and ecommerce-grade product browsing flow.

This should be the final product.

Write the code cleanly and implement the UI fully. Do not stop at a mock header or static layout. Make it feel like a complete storefront.
